# 🎧 Boat_AirpodsAR

An **Augmented Reality (AR) application** built in **Unity** that visualizes **Boat AirPods** in 3D using **multi-marker implementation**.  
The project allows users to scan product markers and view an **interactive 3D model** of the AirPods placed accurately on real-world objects.

---

## 📱 Project Overview

Boat_AirpodsAR is a mobile AR experience designed to showcase a product using **marker-based AR**.  
It leverages **multiple markers** to improve tracking stability and enhance object placement accuracy on a **single 3D model**.

This project is ideal for:
- 📦 Product visualization  
- 🛍️ AR-based marketing demos  
- 🎥 Interactive product showcases  

---

## ✨ Key Features

- ✅ **Marker-Based AR**
  - Detects physical product markers in real time
  - Anchors 3D AirPods model precisely on the marker

- 🔁 **Multi-Marker Implementation**
  - Uses multiple image targets for improved tracking
  - Ensures stable object positioning from different angles

- 🎮 **Interactive 3D Object**
  - Real-time 360° visualization
  - Smooth rotation and scaling of the AirPods model

- 📲 **Android APK Available**
  - Fully working APK build
  - Ready for installation and demo use
